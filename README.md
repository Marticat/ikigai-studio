# IKIGAI — гардеробные и наполнение

Серый интерьерный сайт на русском: каталог MEIDU, подборка, конструктор с визуализацией, комплекты и управление каталогом.

## Запуск и сборка

Node 20.20+; `npm ci`, затем `npm run db:local` (один раз для новых миграций) и `npm run dev`. Адрес: http://127.0.0.1:4173. Локальный вход имитирует аккаунт preview@sites.test только в отдельном preview-worker. Это не настоящий вход и он не входит в production.

`npm run build` создаёт `dist/server/index.js` и `dist/client`. Исходники страниц находятся в `public/`. Старый запуск через python HTTP server больше не подходит: каталог теперь требует сервер API. Для другого хостинга нужен совместимый Worker/D1/R2 или перенос серверной части; Vercel-версия пользователя не изменяется.

## Каталог и управление

79 исходных товарных страниц MEIDU (4–82), 6 категорий, 27 серий. Это записи страниц, а не подтверждённые уникальные артикулы. Повторяющиеся обозначения MD могут относиться к профилям; источник и номер страницы сохраняются. Все исходные цены — по запросу. Доступность товара не заявляется.

`admin.html`: добавить изделие; изменить название, модель, описание, характеристики, раздел/серию, цену в тенге и единицу; загрузить фото; скрыть или вернуть товар. Новые товары относятся к существующим разделам/сериям. Пустая цена = по запросу. Фотографии JPG/PNG/WebP до 5 МБ; браузер декодирует и пересохраняет их, сервер проверяет формат и размер. Исходные листы MEIDU сохраняются отдельно от заменённого фото.

Правки хранятся в D1 `catalog_edits`, фото в R2. Исходный каталог остаётся в `public/catalog.mjs`; правки накладываются при чтении API, поэтому новый деплой не стирает товары. Добавление колонок — только через новые миграции Drizzle. Применённые миграции не менять. Параллельное сохранение проверяет revision; устаревшая карточка не перезаписывает новую. Для восстановления после конфликта скопировать свои правки и открыть карточку заново — данные запрашиваются с сервера.

Вход через ChatGPT/Sites. Каждая операция API проверяет платформенный ID и email из серверного списка `CATALOG_ADMIN_EMAILS` (через запятую). Значение задаётся в настройках окружения Sites, не в исходниках. Сейчас разрешён только владелец. Email Рустема пока нет; для него понадобятся и доступ к частному сайту, и добавление email в список редакторов, затем деплой окружения. Простое приглашение посетителя не делает его редактором.

Аудитория сайта остаётся закрытой для владельца. Публикация новой версии не делает сайт общедоступным. Для запуска магазина для клиентов отдельно согласовать публичный доступ.

## Заявки и комплекты

В карточке изделия форма «Подойдёт ли для моего шкафа?» принимает внутреннюю ширину, высоту, глубину в мм и комментарий. Составляет сообщение в WhatsApp с моделью и страницей каталога; совместимость проверяет менеджер. Сообщение отправляет сам посетитель.

Три стартовых комплекта: `configurator.html?kit=small`, `?kit=family`, `?kit=glass`. Явный комплект имеет приоритет над ранее сохранённым эскизом. Размеры, наполнение, стекло, профиль и свет можно менять. Это концепции, не подтверждённые складские наборы. Визуализации созданы по мотивам каталога и подписаны как концепты.

Конструктор: ширина 180–420 см, высота 220–300 см, глубина 60 см. Три наполнения, три профиля, четыре варианта стекла, три режима света. Эскиз сохраняется в браузере. Смета демонстрационная с диапазоном ±15%; это не прайс IKIGAI, доставка и монтаж не включены. Реальные цены каталога не меняют демонстрационные ставки конструктора.

Подборка хранится локально и синхронизируется между вкладками. WhatsApp: +7 701 999 67 99. Ни одна форма не отправляет сообщение автоматически. Онлайн-оплата не подключена; банковские данные не собираются.

## Проверка

`npm test` — 27 проверок исходного каталога, поиска, подбора, конфигураций, заявок, авторизации и проверки данных. Схема без одежды и аксессуаров: во всех трёх наполнениях сохраняются полки, штанги, ящики, стекло, свет и размеры.

`public/motion.mjs` и `motion.css` добавляют появление заголовков/карточек, движение фотографий при прокрутке, плавный первый экран и отклик кнопок. Новые карточки подключаются после поиска/фильтрации; удалённые элементы освобождаются. Системная настройка уменьшения движения отключает CSS- и JS-анимации. На мобильных ограничены фоновые движения; прокрутка остаётся обычной. Изменение размеров в конструкторе не перезапускает переход сцены.

С запущенным локальным сервером: `node scripts/check-local-api.mjs` проверяет реальный D1/R2: создание, сохранение, чтение после повторного запроса, конфликт ревизий, скрытие, загрузку фото, ограничения доступа и подделку заголовков, отсутствие preview-входа в production. Создаёт скрытую тестовую карточку только в локальной базе.

Проверены браузером форма размеров, комплекты, применение настроек конструктора, вход, редактирование/перезагрузка, загрузка фото и новая скрытая карточка; десктоп и мобильная ширина. Сообщения в WhatsApp не отправлялись. Тестовые цены/карточки остаются только в локальной базе и в публикацию не входят.
